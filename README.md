# 🧠 HR Analytics: Employee Attrition Analysis

This project uses a publicly available HR dataset to analyze factors that contribute to employee attrition using Python. It includes data exploration, statistical testing (like Pearson correlation), and visualizations to uncover trends and patterns in workforce behavior.

---

## 📊 Dataset

- **Source:** IBM HR Analytics Employee Attrition & Performance dataset
- **File:** `WA_Fn-UseC_-HR-Employee-Attrition.csv`
- **Records:** 1,470 employees
- **Features:** Age, Attrition, Department, Education, EnvironmentSatisfaction, JobLevel, TotalWorkingYears, and more.

---

## 🎯 Objectives

- Analyze factors correlated with employee attrition
- Identify statistically significant relationships between features
- Visualize trends with graphs and charts
- Provide actionable insights for HR decision-making

---

## 🔍 Features Analyzed

- Age vs Total Working Years
- Monthly Income vs Job Level
- Environment Satisfaction vs Attrition
- Distance from Home vs Attrition
